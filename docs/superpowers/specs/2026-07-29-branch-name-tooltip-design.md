# 分支名称悬浮补全设计

日期：2026-07-29

## 目标

目标分支下拉列表继续以单行省略展示超长分支名；鼠标停留在任一分支选项时，由浏览器原生提示展示该分支的完整名称，避免为了辨认名称改变列表宽度或展开行高。

## 交互

- 分支行保持当前布局、远端标记和选中状态。
- 每个分支选项的悬浮提示内容只使用完整分支名，不截断，也不追加装饰文案。
- 完整分支名仍保留在按钮文本和无障碍名称中，键盘用户及读屏软件无需依赖鼠标提示。
- 不增加自定义浮层、动画或新的状态管理。

## 实现范围

在 `SearchableBranchSelect` 渲染的分支选项上设置原生 `title` 属性。基准分支使用系统 `select`，不在本次范围内。

## 验证

- 自动化测试检查搜索分支选项绑定完整分支名作为 `title`。
- 运行 lint、构建和完整测试。
- 部署到本机 GitDiff 运行目录后，确认页面与只读 Git API 正常启动。
